# 📝 To-Do List Application

A simple, interactive, and responsive **To-Do List Web Application** developed using HTML, CSS, and JavaScript as part of my Web Development Internship at **Thiranex EduTech LLP**.

The application helps users manage their daily tasks efficiently by allowing them to add, edit, delete, and filter tasks. It also uses browser Local Storage to save tasks automatically, ensuring that data remains available even after refreshing the page.

## 🚀 Features

- **Add Tasks:** Add new tasks to your to-do list.
- **Read Tasks:** View all added tasks in one place.
- **Update Tasks:** Edit existing tasks whenever required.
- **Delete Tasks:** Remove individual tasks.
- **Task Filtering:** Filter tasks into three categories:
  - All
  - Active
  - Completed
- **Local Storage:** Automatically saves tasks in the browser.
- **Clear Completed:** Remove all completed tasks at once.
- **Task Counter:** Displays the number of remaining active tasks.
- **Responsive Design:** Simple and user-friendly interface.

## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling, layout, and responsive design.
- **JavaScript (Vanilla JS)** – Application logic and functionality.
- **DOM Manipulation** – Dynamically updates task elements.
- **Local Storage** – Stores task data in the browser.
